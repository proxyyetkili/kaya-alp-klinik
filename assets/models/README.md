# Kaya Alp diş modeli

Ana sayfadaki 3D diş, `sscript.js` içinde Three.js ile yerel olarak oluşturulur.

- Harici model dosyasına veya internetten yüklenen bir 3D varlığa bağlı değildir.
- Vida, implant gövdesi ve tarama halkası içermez.
- Hero alanından çıkıldığında sağ alt köşede küçük, etkileşimli bir model olarak çalışmayı sürdürür.
- Kullanıcı hero alanına döndüğünde yeniden büyük hero konumuna geçer.
